입금 요청 앱 설치 안내

사장님 폰에 앱을 깔고 상단바 알림을 켜는 방법입니다. 처음 한 번만 하면 됩니다.

버튼 4번이면 끝약 1분
빠른 설치 (권장)앱 안 버튼만 차례로 누르세요
  1. 1
    카톡에서 열었다면 위쪽 노란 줄의 [인터넷 앱으로 열기]
  2. 2
    [📲 앱 설치] → 설치 · 앱스 화면에 ₩ 입금요청이 생깁니다
  3. 3
    ₩ 입금요청으로 열고 🔔 → 이 폰에서 알림 받기 → 허용 → 비밀번호
  4. 4
    테스트 알림 보내기 → 상단바에 「🔔 알림 테스트」가 뜨면 끝
🎬 움직이는 안내로 보기
버튼이 안 보이거나 안 될 때 · 직접 설치카톡 → 인터넷 앱 → 앱스에 추가
1

카톡에서 링크를 열었다면

카톡 안에서는 설치가 안 됩니다. 화면 오른쪽 아래 ⋮ 를 누르세요.

2

「다른 브라우저로 열기」

다른 브라우저로 열기를 누르면 폰의 인터넷 앱으로 다시 열립니다.

3

⋮ 메뉴 → 「현재 페이지 추가」

인터넷 앱 오른쪽 아래 ⋮(메뉴)를 누르고 현재 페이지 추가를 누르세요.

4

「웹앱으로 설치」

추가할 곳 목록에서 웹앱으로 설치를 고르세요.

5

「추가」

「앱스 화면에 이 웹페이지를 추가할까요?」에서 추가.

6

경고 창이 뜨면 「확인」

「Google Play 프로텍트 · 안전하지 않은 앱 차단됨」은 인터넷 앱이 아이콘을 만들 때 나오는 안내입니다. 확인을 누르면 그대로 추가됩니다.

7

설치 끝

「입금요청을(를) 앱스에 추가했어요」가 뜨면 끝입니다. 이제부터는 앱스 화면의 ₩ 입금요청 아이콘으로 여세요.

상단바 알림 켜기 (그림)🔔 → 알림 받기 → 허용
8

오른쪽 위 🔔

₩ 입금요청 앱을 열고 오른쪽 위 🔔를 누르세요. 빨간 점은 “아직 알림이 꺼져 있다”는 뜻입니다.

9

「이 폰에서 알림 받기」 → 「허용」

버튼을 누른 뒤 뜨는 알림 허용 창에서 허용을 누르세요.

10

사장님 비밀번호

처음 한 번 숫자 4~8자리를 정합니다. 입금 완료 처리에도 같은 비밀번호를 씁니다.

11

「테스트 알림 보내기」

상단바에 「🔔 알림 테스트」가 뜨면 완료입니다. 이제 지점이 입금 요청을 올리면 바로 알림이 옵니다.

아이폰이라면

사파리에서 열고 아래 공유(□↑) → 홈 화면에 추가 → 홈 화면의 「입금요청」 아이콘으로 연 뒤 8번부터 하세요. iOS 16.4 이상에서 됩니다.

알림이 안 올 때

폰 설정 → 알림에서 「입금요청」(또는 「인터넷」) 알림이 켜져 있는지 확인하세요. 앱의 🔔를 열면 마지막 알림이 갔는지와 실패 이유가 보입니다.
